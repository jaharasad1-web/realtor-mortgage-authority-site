DEPLOY
1. Upload assets/theme-override.css into /assets
2. Upload both HTML pages to repository root.
3. To apply the new colors to the EXISTING site immediately, add this line after assets/site.css in each HTML <head>:
   <link rel="stylesheet" href="assets/theme-override.css">
4. Commit to main. Cloudflare Pages should rebuild automatically.
