TRMM CLOUD RELATIONSHIP CENTER — LEAD BRIDGE SETUP

WHAT THIS PACKAGE DOES
1. Facebook ad sends prospect to matching landing page.
2. Prospect submits the form.
3. Cloudflare Pages Function /api/lead validates the submission.
4. It creates or updates the lead in Supabase table: families.
5. It writes a website_lead event into: contact_timeline.
6. Campaign source is preserved as First-Time Homebuyer or Down Payment Assistance.
7. Spam controls: honeypot + minimum-submit-time + strict campaign/state validation.
8. Supabase service-role key stays SERVER-SIDE only.

FILES TO UPLOAD TO YOUR CLOUDFLARE PAGES GITHUB REPOSITORY ROOT
- first-time-homebuyer.html
- down-payment-assistance.html
- assets/
- functions/api/lead.js

CLOUDFLARE PAGES SECRETS / VARIABLES
Cloudflare Dashboard:
Workers & Pages > your Pages project > Settings > Variables and Secrets

Add:
SUPABASE_URL = your existing TRMM CRM Supabase project URL
SUPABASE_SERVICE_ROLE_KEY = your existing Supabase service_role key  [SECRET]
Optional:
ALLOWED_ORIGINS = comma-separated additional approved origins

IMPORTANT
Never place SUPABASE_SERVICE_ROLE_KEY inside HTML or browser JavaScript.
It belongs only in the Cloudflare Pages secret.

AFTER SAVING THE VARIABLES
Redeploy the Pages project.
